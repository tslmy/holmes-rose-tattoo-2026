Code archive: what each removed script did, and where to get it back

Rendered from docs/code-archive.md, a working record of the project.

On 2026-11-22, after Phase 2 closed, the scripts in tools/ were checked against the current pipeline (Linear LMY-57). This is the code counterpart of pack-archive.md, which covers the art packs these scripts produced. A script was removed only when nothing used it: not the remaster CLI (tools/remaster/), not remaster.toml, not a test under tools/tests/, not another kept script, and no tree we still keep needs it to be rebuilt. All the removed scripts come from the August 2026 ChatGPT/Codex effort.

Every removed file is still in origin/main at 3426470 (the last commit before the removal). The "Last change" column is the last commit that edited the file. To restore one:

git show 3426470:tools/flux_redraw_rosetattoo_backgrounds.py > tools/flux_redraw_rosetattoo_backgrounds.py

Kept, and why

Used by the pipeline or its tests:

  • Extractors driven by the extract stage: extract_rosetattoo_assets.py, extract_rosetattoo_sprites.py, extract_rosetattoo_room_sprites.py, extract_rosetattoo_canimations.py, and the extraction audit audit_rosetattoo_extraction.py.
  • upscale_rosetattoo_sprites.py (ESRGAN; baseline stage, remaster.toml) and smoke_rosetattoo_scenes.py (smoke stage).
  • build_remaster_pack.py (builds the playable pack; tested), which calls assemble_rosetattoo_playable_pack.py, and redraw_rosetattoo_map.py (the redrawn map, --map).
  • sprite_metadata.py: shared helper imported by the sprite scripts and tests.
  • tools/opencode/: used by remaster delegate.

Needed to rebuild trees we keep, or tested, or referred to by current docs:

  • The October sprite work that made the kept enhanced/*-remaster-20261031 baselines and the contour trees: temporal_upscale_rosetattoo_sprites.py (enhanced/sprites-temporal, which every pack ships), prepare_rosetattoo_shared_sprites.py, extract_rosetattoo_palette_walks.py, extract_rosetattoo_vgs_variants.py, refine_rosetattoo_sprite_alpha.py, and their audits audit_rosetattoo_palette_walks.py, audit_rosetattoo_sprite_contours.py, audit_rosetattoo_pack.py, validate_rosetattoo_contour_plan.py, assemble_rosetattoo_modernized.py. Each has a test; Phase 3 compares against these baselines.
  • upscale_rosetattoo_backgrounds.py: made enhanced/esrgan-hires-backgrounds (kept; --method external).
  • prepare_animation_redraw.py: made generated/animation-redraws, which build_remaster_pack.py still passes to every pack.
  • playtest_rosetattoo.py, playtest_ui_suite.py, playtest_canim_suite.py, tools/playtest_scripts/: the Phase 6 play-test tooling (playtest-input-script.md).
  • run_rosetattoo_validation.py: the ScummVM launcher (tested; root README).
  • polish_rosetattoo_prompts.py and profiles/neural/prompt-briefs/: the prompt briefs, read by tools/img2img/common.py; local-models.md documents the current invocation.
  • generate_rosetattoo_state_masks.py: story-flag masks mirroring the engine's object rule. Unused now, but kept because the Phase 3/4 story-state work (objects from other states, 01WLLCVR) may need it.
  • tools/img2img/ (common.py, sdxl_controlnet.py, z_image*.py, download_zimage_cuda_models.py): not used by the pipeline, but common.py, sdxl_controlnet.py and z_image_controlnet_cuda.py had uncommitted edits from another session on 2026-11-22, so they were left alone. Candidates for the next prune once that work lands or is dropped.
  • thor-package/: a Flatpak ScummVM launcher and .desktop entry for a Linux machine (stock ScummVM, no overrides). Not part of the pipeline, but 24 lines and the only record of that setup.
