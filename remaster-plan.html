Rose Tattoo remaster: plan (moved to Linear)

Rendered from docs/remaster-plan.md, a working record of the project.

The plan, phases and task tracking now live in Linear, project Rose Tattoo remaster (team LMY): (Linear, private)

Where things are:

  • Design and plan: the project document "Remaster plan" (Linear, private): facts that shape the design, design decisions, target pipeline, QA gates, local delegation, risks, decisions taken.
  • Phases: milestones "Phase 0: Foundations" to "Phase 6: Validation and release". Each holds the phase's description, its Done when line and (for Phase 2) the ownership notes.
  • Work and findings: issues in the project, under the right milestone. Delivered phases (0, 1) and Phase 2 Iterations 1-6 are Done issues.
  • Approvals: issues labelled "Needs approval", assigned to the user, each stating the provisional default in use. The runner still writes review/queue.md; new pending items are mirrored into Linear.

Results docs stay in the repo as records, and Linear links to them: docs/bakeoff-results.md, docs/local-models.md, docs/pilot-lessons.md, work/playtest/ui-findings.md, and the other results docs.

Source on GitHub · Screenshots and redraws are of The Lost Files of Sherlock Holmes: The Case of the Rose Tattoo (Mythos Software / Electronic Arts, 1996), shown downscaled for commentary. The game's data is not included in the repository.
